# issue-record-management: platform references

| Platform | Procedure | Scope | Notes |
|---|---|---|---|
| GitHub | [github/procedure.md](github/procedure.md) | List/read/create/update repository issues; list/add comments | Pull requests can appear in issue lists; exclude them when issue-only output is requested. |
| GitLab | [gitlab/procedure.md](gitlab/procedure.md) | List/read/create/update project issues; list/add notes | Project issue IID, not global issue ID. |
| Jira Cloud | [atlassian_jira/procedure.md](atlassian_jira/procedure.md) | JQL search/read, create/edit, workflow transitions, list/add comments | Cloud REST v3; metadata resolves project-specific fields and transitions. |
