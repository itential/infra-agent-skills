# RFC Editor document lookup: bindings

Official navigation targets:

| Operation | Publisher location |
|---|---|
| Search | `https://www.rfc-editor.org/search/` |
| Browse | Follow the publisher's Browse all RFCs link from `https://www.rfc-editor.org/series/rfc/` |
| Document | Follow the resolved RFC page and its section links; do not guess a third-party MCP response contract |
| Errata | Follow the RFC page's Errata sidebar or `https://errata.rfc-editor.org/` |

The search page returned HTTP 429 during verification on 2026-10-09. Its existence is verified through publisher navigation, but its current automated request parameters are not. Browser navigation is the supported binding here.
